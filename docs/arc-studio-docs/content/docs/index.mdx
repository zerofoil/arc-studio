## What is ARC Studio?

**ARC Studio** is a visual node based Discord bot creator, built with [Node.js](https://nodejs.org/), [Tauri](https://v2.tauri.app/), [React](https://react.dev/), [Vite](https://vite.dev/) and the [Chezcord](https://github.com/relentiousdragon/arc-studio/tree/main/packages/chezcord) library.  
It is used for creating Discord bots using nodes, which you can export and run it's final version anywhere using Node.js.
