---
title: "Get Channel Messages"
---

Fetches up to 100 recent messages from a channel. Requires View Channel and Read Message History.

## Inputs

- Channel ID (string)
- Limit (number)
- Before Message ID (string)
- After Message ID (string)
- Around Message ID (string)

## Outputs

- Messages (array)
- Count (number)
- First Message (object)
- Last Message (object)
- Success (boolean)
