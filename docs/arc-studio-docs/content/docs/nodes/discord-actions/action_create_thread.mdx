---
title: "Create Thread"
---

Creates a public or private thread inside a text channel. Requires the matching thread permission.

## Inputs

- Parent Channel ID (string)
- Message ID (Optional) (string)
- Thread Name (string)
- Thread Type (number)
- Auto Archive (minutes) (number)
- Slowmode (seconds) (number)
- Members Can Invite (boolean)
- Audit Log Reason (string)

## Outputs

- Thread ID (string)
- Parent Channel ID (string)
- Success (boolean)
