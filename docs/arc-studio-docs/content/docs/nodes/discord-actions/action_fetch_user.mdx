---
title: "Get User Info"
---

Fetches a Discord user profile and exposes both the full user object and common profile fields

## Inputs

- User ID (string)

## Outputs

- User Object (object)
- User ID (string)
- Username (string)
- Display Name (string)
- Discriminator (string)
- Avatar Hash (string)
- Is Bot (boolean)
- Public Flags (number)
- Success (boolean)
