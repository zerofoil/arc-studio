---
title: "Get Message"
---

Fetches one message by channel and message ID. Requires View Channel and Read Message History.

## Inputs

- Channel ID (string)
- Message ID (string)

## Outputs

- Message Object (object)
- Message ID (string)
- Channel ID (string)
- Content (string)
- Author ID (string)
- Timestamp (string)
- Edited At (string)
- Attachments (array)
- Embeds (array)
- Components (array)
- Pinned (boolean)
- Success (boolean)
