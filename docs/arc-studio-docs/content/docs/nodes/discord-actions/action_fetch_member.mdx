---
title: "Get Server Member"
---

Fetches a member in a server and exposes the full member and user objects, roles, and profile fields

## Inputs

- Server ID (string)
- User ID (string)

## Outputs

- Member Object (object)
- User Object (object)
- User ID (string)
- Username (string)
- Nickname (string)
- Role IDs (object)
- Joined At (string)
- Boosted Since (string)
- Server Deafened (boolean)
- Server Muted (boolean)
- Membership Pending (boolean)
- Success (boolean)
