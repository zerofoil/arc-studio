---
title: "Create Channel"
---

Creates a text, voice, category, announcement, stage, forum, or media channel. Requires Manage Channels.

## Inputs

- Server ID (string)
- Name (string)
- Channel Type (number)
- Category ID (string)
- Permission Overwrites (object)
- Topic (string)
- Channel Flags (number)
- Slowmode (seconds) (number)
- Bitrate (bits/sec) (number)
- User Limit (number)
- Position (number)
- Default Thread Archive (minutes) (number)
- Forum Tags (object)
- Age Restricted (boolean)
- Audit Log Reason (string)

## Outputs

- Channel ID (string)
- Success (boolean)
