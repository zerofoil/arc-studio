---
title: "Moderate Member"
---

Times out, kicks, bans, or unbans a server member. Route failures through the Failed output.

## Inputs

- Server ID (string)
- User ID (string)
- Action (string)
- Timeout (minutes) (number)
- Ban message deletion (seconds) (number)
- Reason (string)

## Outputs

- Success (boolean)
- Error (string)
