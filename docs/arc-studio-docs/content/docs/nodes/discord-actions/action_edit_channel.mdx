---
title: "Edit Channel"
---

Changes a channel name, topic, or category. Requires Manage Channels.

## Inputs

- Channel ID (string)
- Thread ID (Optional) (string)
- Name (string)
- Topic (string)
- Category ID (string)
- Permission Overwrites (object)
- Slowmode (seconds) (number)
- Age restricted (boolean)
- Voice bitrate (number)
- Voice user limit (number)
- Voice region (string)
- Voice video quality mode (number)
- Thread auto archive (minutes) (number)
- Archived (boolean)
- Locked (boolean)
- Members can invite (boolean)
- Thread auto archive (minutes) (number)
- Audit Log Reason (string)

## Outputs

- Channel ID (string)
- Success (boolean)
