---
title: "Start Thread from Message"
---

Starts a public thread from an existing message in a text channel.

## Inputs

- Parent Channel ID (string)
- Message ID (string)
- Thread Name (string)
- Auto Archive (minutes) (number)
- Slowmode (seconds) (number)
- Audit Log Reason (string)

## Outputs

- Thread ID (string)
- Parent Channel ID (string)
- Success (boolean)
