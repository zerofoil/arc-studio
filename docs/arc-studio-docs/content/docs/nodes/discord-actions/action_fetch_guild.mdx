---
title: "Get Server Info"
---

Fetches a Discord server and exposes its full server object, owner, features, and common settings

## Inputs

- Server ID (string)

## Outputs

- Server Object (object)
- Server ID (string)
- Name (string)
- Owner ID (string)
- Description (string)
- Icon Hash (string)
- Approx. Members (number)
- Features (object)
- Preferred Locale (string)
- Verification Level (number)
- Success (boolean)
