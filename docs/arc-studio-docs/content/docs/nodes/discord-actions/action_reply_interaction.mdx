---
title: "Reply to Interaction"
---

Responds to an interaction within Discord’s 3 second initial response window, or edits a deferred response

## Inputs

- Application ID (string)
- Interaction ID (string)
- Interaction Token (string)
- Reply Content (string)
- Embed (Optional) (embed)
- Components (Optional) (object)
- Files (optional) (object)
- Ephemeral (Hidden) (boolean)

## Outputs

- Interaction ID (string)
- Application ID (string)
- Interaction Token (string)
- Message ID (string)
- Response Message (object)
- Success (boolean)
