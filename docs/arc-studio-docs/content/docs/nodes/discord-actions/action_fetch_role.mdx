---
title: "Get Role Info"
---

Fetches a server role and exposes its name, color, position, permissions, and full object.

## Inputs

- Server ID (string)
- Role ID (string)

## Outputs

- Role Object (object)
- Role ID (string)
- Name (string)
- Color (number)
- Color Hex (string)
- Show Separately (boolean)
- Mentionable (boolean)
- Managed (boolean)
- Position (number)
- Permissions Bitfield (string)
- Icon Hash (string)
- Unicode Emoji (string)
- Role Flags (number)
- Role Tags (object)
- Success (boolean)
