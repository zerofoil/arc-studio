---
title: "Get Channel Info"
---

Fetches a channel and exposes its name, type, topic, parent, and full object.

## Inputs

- Channel ID (string)

## Outputs

- Channel Object (object)
- Channel ID (string)
- Name (string)
- Channel Type (number)
- Server ID (string)
- Parent ID (string)
- Position (number)
- Permission Overwrites (object)
- Overwrite Count (number)
- Topic (string)
- Age Restricted (boolean)
- Last Message ID (string)
- Channel Flags (number)
- Metadata Obfuscated (boolean)
- Success (boolean)
