---
title: "Create Role"
---

Creates a role with a name, RGB color number, and mentionable setting. Requires Manage Roles.

## Inputs

- Server ID (string)
- Name (string)
- Color (RGB number) (number)
- Permissions Bitfield (string)
- Show separately (boolean)
- Mentionable (boolean)
- Audit Log Reason (string)

## Outputs

- Role ID (string)
- Success (boolean)
