---
title: "Modify Embed"
---

Updates specific fields on an existing embed without rebuilding it

## Inputs

- Base Embed (embed)
- Title (Optional) (string)
- Description (Optional) (string)
- Hex Color (#, optional) (string)
- Image URL (Optional) (string)
- Thumbnail URL (Optional) (string)
- Footer Text (Optional) (string)
- Author Name (Optional) (string)
- Field Name (Optional) (string)
- Field Value (Optional) (string)

## Outputs

- Embed (embed)
