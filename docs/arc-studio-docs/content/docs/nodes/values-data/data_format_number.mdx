---
title: "Format Number"
---

Formats a finite number with locale grouping, decimal, percent, or currency style. Percent style scales the number by 100.

## Inputs

- Value (number)
- Locale (string)
- Style (string)
- Currency (string)
- Minimum decimals (number)
- Maximum decimals (number)

## Outputs

- Formatted (string)
- Valid (boolean)
