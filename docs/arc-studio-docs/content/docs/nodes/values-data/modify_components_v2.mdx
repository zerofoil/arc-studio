---
title: "Modify Components V2"
---

Changes one Components V2 block field while preserving the rest of the layout. Connect the result to a message or interaction reply.

## Inputs

- Components V2 (object)
- Block ID (all for matching blocks) (string)
- Property (string)
- Media Item Index (-1 for all) (number)
- Value (any)

## Outputs

- Components V2 (object)
