---
title: "Embed Builder"
---

Constructs a rich Discord embed object

## Inputs

- Title (string)
- Description (string)
- URL (string)
- Hex Color (#) (string)
- Author (string)
- Author URL (string)
- Author Icon URL (string)
- Footer Text (string)
- Footer Icon URL (string)
- Thumbnail URL (string)
- Image URL (string)

## Outputs

- Embed (embed)
- Components (object)
