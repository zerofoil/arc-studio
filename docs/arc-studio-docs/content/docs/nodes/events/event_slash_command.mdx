---
title: "On Slash Command"
---

Fires when an application slash command is invoked

## Outputs

- Command Name (string)
- Subcommand Group (string)
- Subcommand (string)
- User ID (string)
- Username (string)
- Channel ID (string)
- Server ID (string)
- Application ID (string)
- Interaction ID (string)
- Interaction Token (string)
- Command Arguments (object)
