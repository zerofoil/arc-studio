---
title: "On Audit Log Entry Created"
---

An audit log entry is created. Requires View Audit Log. Discord may merge channel or role position updates, and merged updates may not emit another event.

## Outputs

- Audit Log Entry ID (string)
- Server ID (string)
- Action Type ID (number)
- Target ID (string)
- Acting User ID (string)
- Reason (string)
- Changes (array)
- Options (object)
- Full Audit Log Entry (object)
