---
title: "HTTP Download File"
---

Downloads a public file over HTTP or HTTPS as a bounded binary attachment. Connect File to a message or interaction reply Files input.

## Inputs

- URL (string)
- User-Agent (string)
- Timeout (ms) (number)
- Max file bytes (number)

## Outputs

- File (object)
- File Name (string)
- Content Type (string)
- Bytes (number)
- Error (string)
